## 📜 Sobre o Projeto

O **ShowFlix** é uma plataforma de streaming inspirada na interface da Netflix, desenvolvida para proporcionar uma experiência imersiva de navegação por catálogos de filmes e séries.

O projeto foi construído durante a **Imersão Front-End com IA** da **Alura**, onde o foco foi aplicar conceitos avançados de manipulação do DOM, persistência de dados e, principalmente, a organização de código modular com auxílio de Inteligência Artificial.

---

## ✨ Funcionalidades

* 👤 **Seleção de Perfis:** Interface inicial personalizada com salvamento do perfil ativo no navegador.
* 📺 **Catálogo Dinâmico:** Renderização de múltiplas categorias de conteúdo através de JavaScript.
* 🍿 **Hero Banner:** Destaque principal aleatório que permite assistir ao trailer diretamente no YouTube.
* 🌓 **Dark/Light Mode:** Troca de temas com persistência via `localStorage`.
* 🖱️ **Hover Interativo:** Visualização de trailers automáticos ao passar o mouse sobre os cards.
* ♿ **Acessibilidade:** Uso de HTML semântico e elementos focáveis para uma melhor navegação.
